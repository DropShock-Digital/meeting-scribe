# Architecture diagrams

- `meeting-scribe-architecture.drawio` is the editable diagrams.net source. It has a system-context page and a consent/lifecycle page.
- `meeting-scribe-architecture.svg` is a public-safe preview used in the README.

The diagrams intentionally show boundaries and decisions, not real deployments. They contain no credentials, Discord IDs, hostnames, recordings, or transcript data.
